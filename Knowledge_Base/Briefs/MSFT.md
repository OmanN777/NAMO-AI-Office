# Microsoft (MSFT) - Research Briefing
**Prepared by:** Earnchan & Fundamentokung
**Date:** 2026-06-08

### 1. Snapshot
ยักษ์ใหญ่ด้านซอฟต์แวร์ระดับโลกและเจ้าของระบบ Cloud อันดับสอง (Azure) ที่ผสานพลัง AI ของ OpenAI เข้ากับ Product ของตัวเองอย่างแนบเนียน

### 2. Fundamentals
งาน Microsoft Build 2026 ล่าสุดชี้ชัดว่ากำลังเปลี่ยนผ่านเข้าสู่ยุค "Agentic AI" (Autopilots, Microsoft Scout) และที่สำคัญคือเปิดตัวโมเดล MAI ของตัวเองเพื่อลดการพึ่งพา OpenAI

### 3. Latest Earnings
แม้ผลประกอบการรอบก่อนจะแกร่ง แต่เดือนมิถุนายนนี้หุ้นร่วงลงมา 7-10% ตามแรงเทขายของกลุ่ม Tech ทั่วโลก ทั้งนี้เพิ่งประกาศปันผล $0.91 ต่อหุ้น

### 4. Bull/Bear Case
**Bull:** นักวิเคราะห์อย่าง Wells Fargo ยังให้เป้าสูงถึง $650 เพราะความเป็นผู้นำในการเก็บเงินจาก AI ในระดับ Enterprise (Monetization)
**Bear:** งบลงทุน AI (CapEx) เพิ่มขึ้น 84% YoY ทำให้ตลาดต้องจับตาดูว่าจะคืนทุนได้เร็วแค่ไหน

### 5. Kill Conditions
ความล้มเหลวในการขยายส่วนแบ่งตลาดของ Azure เมื่อเทียบกับ AWS หรือฟีเจอร์ AI เกิดปัญหาความปลอดภัยร้ายแรงในระดับลูกค้าองค์กร

### 6. What to ask
"การที่ MSFT เปิดตัวโมเดล AI ของตัวเอง (MAI) แปลว่าความสัมพันธ์กับ OpenAI เริ่มสั่นคลอนแล้วใช่ไหม?"
