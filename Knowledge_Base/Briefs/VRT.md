# Vertiv Holdings (VRT) - Research Briefing
**Prepared by:** Earnchan & Fundamentokung
**Date:** 2026-06-08

### 1. Snapshot
บริษัทผู้พัฒนาโซลูชันระบบการจัดการโครงสร้างพื้นฐานสำหรับ Data center โดดเด่นเป็นพิเศษเรื่องระบบทำความเย็น (Cooling system) และระบบจัดการพลังงาน

### 2. Fundamentals
อานิสงส์จาก AI Data center ทำให้เป็นที่จับตาหนักมาก เพิ่งเปิดตัวนวัตกรรม "PurgeRite NearZero" เพื่อลดการใช้น้ำและประหยัดต้นทุนในศูนย์ข้อมูล

### 3. Latest Earnings
งบ Q1 2026 ออกมาสวย เติบโต 30% YoY ราคาหุ้นทะยานขึ้นกว่า 87% YTD พร้อมประกาศปันผลรายไตรมาสที่ $0.0625 ต่อหุ้น

### 4. Bull/Bear Case
**Bull:** ตลาดมองว่าเป็นผู้ได้รับผลประโยชน์ทางอ้อม (Derivative play) จากการมาของตู้ AI server ที่กินไฟและสร้างความร้อนมหาศาล
**Bear:** หุ้นวิ่งขึ้นมาแรงเกินไป จนนักวิเคราะห์บางรายเตือนว่าราคาแซงหน้า Intrinsic value ไปมากแล้ว และเริ่มเห็นดีมานด์ฝั่งยุโรปชะลอตัวเล็กน้อย

### 5. Kill Conditions
คู่แข่งหน้าใหม่พัฒนาเทคโนโลยีระบายความร้อนที่ถูกกว่าและดีกว่า (เช่น Liquid cooling รุ่นใหม่) แล้วดึงลูกค้ากลุ่ม Data center ไปหมด

### 6. What to ask
"ถ้า AI Server เริ่มกินไฟน้อยลง (Efficiency ดีขึ้น) จะทำให้ยอดขายระบบระบายความร้อนของ VRT สะดุดไหม?"
