# Teradyne (TER) Q1 2026 Earnings Call Transcript

*Scouted by: Newwy (June 3, 2026)*

**Executives:**
- Greg Smith, CEO
- Sanjay Mehta, CFO

**Key Takeaways (by Newwy):**
1. **AI Testing Complexity:** ชิป AI รุ่นใหม่มีความซับซ้อนสูงมาก ทำให้ระยะเวลาการทดสอบ (Test Time) นานขึ้น ส่งผลดีต่อดีมานด์เครื่องทดสอบของ Teradyne
2. **Memory Test (HBM):** ความต้องการ HBM3E ดันยอดขายเครื่องทดสอบ Memory ฟื้นตัวแรง
3. **Robotics Recovery:** ธุรกิจหุ่นยนต์อุตสาหกรรม (Universal Robots) เริ่มเห็นสัญญาณการฟื้นตัวหลังจากซบเซามานาน

**Guidance:**
คาดว่าดีมานด์ในกลุ่ม Semiconductor Test จะยังคงแข็งแกร่งในช่วงครึ่งปีหลัง ได้รับอานิสงส์จากกลุ่ม 3nm และ AI Accelerators
