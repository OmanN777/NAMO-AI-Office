# แผนปรับโครงสร้างพอร์ต Oman สู่ "โลกแห่งความเป็นจริง"

มะลิเข้าใจจุดประสงค์ของบอสอย่างถ่องแท้แล้วค่ะ! การจำลองสถานการณ์และเสกตัวเลขขึ้นมาเอง (Rigged Simulation) จะไม่ได้ช่วยให้เราหรือ Oman เรียนรู้กลไกตลาดจริงๆ ตามที่บอสบอกเลย "ถ้าเราแก้ไขความเป็นจริงได้ดั่งใจ จะทำไปเพื่ออะไร?"

ดังนั้น มะลิขอเสนอแผน **Re-architecture (ปรับโครงสร้างใหม่ทั้งหมด)** สำหรับพอร์ตจำลองของ Oman ให้กลายเป็น **"พอร์ตเทรดกระดาษ (Paper Trading) ที่อิงกับราคาตลาดจริง"** แบบ 100%

## 📌 แผนการอัปเกรด
1. **ยกเลิกระบบเสกราคา (Hardcoded Prices):**
   - แก้ไขไฟล์ `portfolio/update_portfolio.py` ของ Oman ทิ้งทั้งหมด
   - เปลี่ยนไปใช้ระบบดึงราคาหุ้นจริงจาก **Yahoo Finance (แบบเรียลไทม์)** เหมือนกับที่พอร์ตจริง (Namo) ใช้
2. **ระบบการลงทุนรายวัน (Daily Funding):**
   - scriptจะไม่กดบวกเงิน $20 ทันทีที่รันมั่วซั่วอีกต่อไป
   - ระบบจะเช็ค **วันที่ตามปฏิทินจริง (Real-World Date)** เทียบกับวันที่updateล่าสุด หากเวลาผ่านไปกี่วัน ก็จะคูณ $20 ตามจำนวนวันที่ผ่านไปจริงเท่านั้น ห้ามข้ามเวลาไปอนาคตเด็ดขาด!
3. **การล้างกระดานเริ่มต้นใหม่ (Sync to Reality):**
   - ราคาปัจจุบันของหุ้นในพอร์ต Oman จะถูกจับมา Sync กับราคาตลาดจริง ณ วินาทีนี้ (เช่น VRT ตอนนี้ของจริงอยู่ที่ ~$334 ไม่ใช่ $292 ที่มะลิเสกให้เมื่อวาน)
   - ผลกำไร/ขาดทุน (P/L) ของ Oman จะสะท้อนฝีมือการเลือกหุ้นจริงๆ ไม่ใช่การที่มะลิแต่งหน้าบัญชีให้
