* **คำตอบ:**  
  *"Playwright เป็น Modern Framework ที่ทำงานได้รวดเร็ว รองรับ Auto-waiting, Multi-tab, Iframe และ Cross-browser อย่างมีเสถียรภาพสูงมาก เหมาะอย่างยิ่งสำหรับ Single Page Application (SPA) และระบบ Enterprise SaaS ที่มีความซับซ้อน ส่วน Robot Framework โดดเด่นด้าน Keyword-Driven Testing และการอ่านผล Test Report ที่ชัดเจน ซึ่งผมสามารถประยุกต์ใช้ทั้ง 2 เครื่องมือให้เหมาะกับสถาปัตยกรรมของระบบได้ครับ"*

### Q2: ในระบบ Private Equity SaaS ความถูกต้องของข้อมูล (Data Accuracy) สำคัญมาก คุณมีกลยุทธ์การเทสอย่างไร?
* **คำตอบ:**  
  *"ระบบด้านการเงินต้องใช้กลยุทธ์ Dual-Layer Testing ครับ:  
  1. **API & Database Level:** เขียนสคริปต์ยิง API และเขียน SQL Queries ตรวจสอบการคำนวณตัวเลขทางคณิตศาสตร์และสถานะพอร์ตโฟลิโอโดยตรง ไม่พึ่งพาเพียงแค่หน้า UI  
  2. **E2E Automation:** ใช้ Playwright จำลอง User Journey ในการสร้างธุรกรรม การ Export รายงาน และตรวจสอบว่าค่าที่แสดงผลตรงกับฐานข้อมูล 100%  
  3. **Regression Suite on CI/CD:** รัน Automated Regression ทุกครั้งที่มีการ Deploy โค้ดใหม่ เพื่อป้องกัน Side-Effect ในฟังก์ชันคำนวณเดิมครับ"*
