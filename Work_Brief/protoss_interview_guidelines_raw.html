สวัสดีค่ะ จากที่เรียนสายกันทางโทรศัพท์ ขออนุญาตส่ง Guideline คำถาม+การทดสอบ ดังนี้ค่ะ

 

คำถามคร่าวๆ นะคะ

  • ให้เล่า Flow การทำงาน ตั้งแต่ได้รับ Requirement จนไปถึง Production ว่ามีส่วนร่วมอะไรบ้าง
  • เวลาเขียน Test Case Review ทำร่วมกับใครบ้าง
  • รูปแบบการทำงาน (Agile / Scrum / Waterfall)
  • ทำงานในส่วนไหนบ้าง สามารถทำได้ทั้ง Manual และ Automate เลยไหม
  • ได้รับ Requirement มาจากใคร ก่อนจะทำการเขียนเทส
  • ใช้ Tool อะไรบ้างในการทำงาน
  • หากหยิบการ์ดงานมาทำ แล้วไม่เข้าใจ Requirement จะทำอย่างไร
  • เทส Web หรือว่า Mobile มากกว่ากัน
  • สามารถเทสทั้ง Front-End และ Back-End ได้ไหม
  • เคยเขียน SQL Queue ไหม
  • เคยเทส API ไหม
  • หากเจอเหตุการณ์ที่ทำการเทสอยู่แล้วมีเวลาจำกัด จะทำอย่างไร
  • ถ้ามีเวลาจำกัด จะเลือกเทส Mobile หรือ API ก่อน
  • เวลาเปิดเจอ Defect กรอกอะไรลงใน Jira บ้าง
  • ทีมที่ทำงานร่วมกันมีกี่คน และมีใครบ้าง
  • ทีม Automate กับ ทีม Manual แชร์ Scope งานกันไหม
  • เคยทำงานมากกว่า 1 โปรเจ็คในเวลาเดียวกันไหม (หากเคย มีวิธีการบริหารโปรเจ็คอย่างไร)
  • ถ้าในระหว่างเทสงานอยู่ยังทำไม่เสร็จเรียบร้อย แต่ต้องส่งงานทันที จะจัดการอย่างไร
  • เลือกเคสไหนเป็น Manual และเคสไหนเป็น Automate
  • เคยมี Bug หลุดไปถึง Production ไหม (หากเคย มีวิธีการจัดการอย่างไร)
  • Project ที่ยากที่สุดที่เคยทำงานมา
  • เคยมีปัญหากับคนในทีม หรือ User บ้างไหม
  • เวลาเทส เทสใน Environment ไหนบ้าง

 

การทำเทส 1KS Project

  1. ให้ผู้สมัครลองออกแบบเทสเคสตามโจทย์ที่ได้รับ พร้อมอธิบาย
  2. ให้ผู้สมัครทำการเทส/ออกแบบ API แต่ละเส้น หรืออาจจะให้อธิบายหลักการ เช่น 200 400 401 เป็นต้น
  3. ให้ผู้สมัครเลือกภาษา Programming ที่ถนัดที่สุด (พิจารณาเป็นพิเศษ หากเป็น TypeScript / JavaScript) จากนั้นแชร์จอแล้วทำการ Coding ให้ดูตามโจทย์ที่ได้รับ

 

 

ทั้งนี้ เป็นเพียงแนวทางคำถามและการทำเทสที่อาจจะมีการสัมภาษณ์ประมาณนี้นะคะ อาจมีการปรับเปลี่ยนคำถาม/การทำเทส ตามความเหมาะสมของผู้สมัครแต่ละท่านค่ะ
