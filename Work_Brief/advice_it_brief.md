## 💬 3. Key Interview Q&A Preparation (เตรียมตอบคำถามสัมภาษณ์เฉพาะของ Advice IT)

### Q1: ทำไมถึงสนใจสมัครงานที่ Advice IT Infinite?
* **แนวทางตอบ (Winning Pitch):**  
  *"Advice เป็นผู้นำด้านค้าปลีกและค้าส่งสินค้าไอทีที่มีทั้งช่องทางหน้าร้านกว่า 300 สาขาทั่วประเทศและแพลตฟอร์ม E-Commerce ออนไลน์ขนาดใหญ่ การได้เข้ามาทำหน้าที่ Software Tester ที่นี่จะทำให้ผมได้ใช้ทักษะการทดสอบระบบที่ครอบคลุม ทั้งระบบ E-Commerce, ระบบจัดการสต็อก และระบบ POS หน้าร้าน ซึ่งตรงกับความเชี่ยวชาญด้าน Web & API Testing ของผม อีกทั้งสำนักงานใหญ่บนถนนราชพฤกษ์ยังตั้งอยู่ใกล้กับบ้านของผมในโซนบางบัวทอง ทำให้มีความพร้อมเต็มที่ทั้งด้านการเดินทางและเวลาในการทุ่มเทให้กับการทำงานครับ"*

### Q2: ประสบการณ์ฝึกงาน 8 เดือนที่ผ่านมา ทำอะไรมาบ้าง?
* **แนวทางตอบ:**  
  *"ตลอดการฝึกงาน 8 เดือน ผมได้ลงมือปฏิบัติงานจริงแบบ End-to-End ตั้งแต่วิเคราะห์ Requirement (SRS), ออกแบบ Test Case และ Test Scenario ครอบคลุมทั้ง Positive และ Negative Cases, ทำการทดสอบ Functional Testing และ Regression Testing รวมถึงการยิงทดสอบ REST API ด้วย Postman และเขียน Automated Script ด้วย Robot Framework (Python) และ Playwright เพื่อลดเวลาในการทำ Regression Test ครับ"*

### Q3: หากระบบ E-Commerce ของ Advice มีโปรโมชั่น Flash Sale คุณจะมีกลยุทธ์การทดสอบอย่างไร?
* **แนวทางตอบ:**  
  1. **Functional Test:** ตรวจสอบความถูกต้องของการคำนวณส่วนลด, คูปอง, โค้ดโปรโมชั่น, และการตัดสต็อกสินค้าตามลำดับก่อน-หลัง (Concurrency)
  2. **Payment & Order Flow:** ทดสอบการเชื่อมต่อ Payment Gateway และการสร้างเลขออเดอร์
  3. **Data Verification:** ตรวจสอบ Database SQL ว่าข้อมูลสถานะคำสั่งซื้อและสต็อกคงเหลือตรงกันจริง
  4. **Edge Cases:** ทดสอบกรณีผู้ใช้กดสั่งพร้อมกันในเสี้ยววินาที หรือกรณีกดยกเลิกกลางคัน
