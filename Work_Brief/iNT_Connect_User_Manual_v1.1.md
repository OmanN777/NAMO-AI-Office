# 🏢 Project Summary: iNT Connect System (Mahidol University)

## 📌 Project Overview
* **Project Name:** iNT Connect Platform (Phase 3) - Mahidol University
* **Developer Partner:** Course Square Co., Ltd.
* **Target Audience:** Researchers, Professors, Students, Entrepreneurs, Startups, and Super/Department Admins.
* **Key Platform Features:**
  1. **Intellectual Property (IP) Management:** Search and filter patent/copyright contents.
  2. **Expertise & Laboratory Database:** Database mapping university research experts and lab facilities.
  3. **Startup Incubation & Consult Request (Ticket System):** Consult request ticketing system with status updates, category routing, and admin dashboards.
  4. **Multi-Role User Management:** Super Admin, Department Admin, and Registered User roles.
  5. **Cross-Platform Responsive Web & Mobile:** Fully responsive web application across Desktop, iOS, and Android.
